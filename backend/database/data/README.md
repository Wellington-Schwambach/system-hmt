# Dados de estados e municípios

Arquivos usados pela migration `2026_08_14_090000_create_brazil_locations_and_split_employee_address.php`.

- `brazil_states.csv`: 27 unidades federativas.
- `brazil_cities.csv`: 5.571 localidades municipais/equivalentes, incluindo Brasília, Fernando de Noronha e Boa Esperança do Norte.

Fonte de códigos e nomes: projeto aberto `kelvins/municipios-brasileiros`, baseado nos códigos de localidades do IBGE.
